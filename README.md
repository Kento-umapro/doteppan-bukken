# どてっぱん 出店物件情報サイト

GitHub Pages: https://kento-umapro.github.io/doteppan-bukken/

## データ構造（data.json）

```
{
  "generated": "YYYY-MM-DDTHH:MM",
  "prefs":   { "都道府県名": { "note": "...", "items": [ ... ] } },   // 標準物件
  "premium": { "都道府県名": { "note": "...", "items": [ ... ] } }    // 上級物件（1等立地）
}
```

`prefs` と `premium` の item は同じ形式（ll / sc / rk / pr / s / n / a / st / t / r / rs / tk / d / c / f / fn / tel / u / ad）。
トップページのタブで「標準物件」「上級物件（1等立地）」を切り替えて表示する。

## 掲載基準

共通: 23〜40坪・単一フロア・飲食店営業可（重飲食可が理想）・出店偏差値50以上のみ掲載
（偏差値は既存12店舗の実績と比較した出店評価。50＝既存店平均）

| 区分 | 坪単価（共益費・管理費込み） | 月額賃料 |
|---|---|---|
| 標準物件（prefs） | 8,000円〜20,000円 | — |
| 上級物件（premium） | 2万円超〜4万円 | **100万円以下** |

上級物件は、賃料が標準基準を超えていても立地の集客力により既存店平均以上の収益
（偏差値50以上）が見込めると判定された1等立地物件のみを掲載する特別枠。

## 運用

- 毎朝の自動巡回は新着を `prefs` に「判定待ち」（sc なし）で追加し、掲載30日超を除外する。
  **上級基準（坪単価2万円超〜4万円・月額100万円以下）に該当する募集は `premium` に追加すること。**
- 判定作業で sc / rk / pr を付与し、偏差値50未満は削除する。

### スコア判定の必須手順（物件スコア判定ツール）

1. 住所欄に物件の住所を入力したら、付加情報の**「半径100m以内の同業態競合数」の右にある「🌐 Googleで自動取得」ボタンを必ず先に押す**。
2. **3秒ほど待って競合数が入力欄に反映されたことを確認**する
   （周辺の同業態・飲食店データによる加点・減点がここで判定に入る）。
   見つからない場合は Google Maps で目視カウントして手動入力する。
3. 数値が入ってから「スコア判定」を押す。
4. これを**全物件**で実施する。自動取得（または目視カウント入力）を省略した判定は無効とし、やり直すこと。
