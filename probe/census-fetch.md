# 国勢調査 500mメッシュ 人口データ取得メモ

令和2年(2020年)国勢調査「4次メッシュ(500m)」の男女・年齢別人口を e-Stat 統計地理情報システム(GIS)から取得した記録。

## 1. 到達性確認 (2026-08-14)

| URL | HTTP |
|-----|------|
| https://www.e-stat.go.jp/ | 200 |
| https://data.e-stat.go.jp/ | 301 (→ www.e-stat.go.jp へリダイレクト) |
| https://nlftp.mlit.go.jp/ | 200 |

いずれも認証不要・無料。今回は e-Stat GIS のみ使用(MLIT/国土数値情報は未使用)。

## 2. データ入手先とダウンロードAPI

e-Stat 統計地理情報システムの「統計データダウンロード」機能を利用。
GUIを介さず直接 zip(CSV) を取得できるエンドポイント:

```
https://www.e-stat.go.jp/gis/statmap-search/data?statsId=<統計表ID>&code=<1次メッシュコード>&downloadType=2
```

- `downloadType=2` … CSV(zip圧縮, Shift_JIS/CP932)
- `code` … 1次メッシュ(80km四方)コード。県単位ではなくメッシュ単位で分割配信される
- レスポンスは `application/octet-stream` の zip。中身は `tblT001101H<code>.txt`(CSV実体)

### 統計表IDの調査結果

| statsId | 内容 | メッシュ次数 | 採否 |
|---------|------|------------|------|
| **T001101** | 男女別人口・年齢別人口・世帯数 | **4次(500m, KEY_CODE 9桁)** | ★採用 |
| T001102 | 同上 | 5次(250m, KEY_CODE 10桁, 秘匿多数) | 不採用(細かすぎ) |
| T000847 | 男女・年齢別人口 | 4次(500m) | 不採用(**平成27年=2015年** の表) |

→ **2020年・500mメッシュ・年齢別**は `T001101` が該当。

## 4. 成果物

- `tools/census/mesh500_pop.csv` … マージ済みデータ(UTF-8)。**89,028行**(ヘッダ除く)
- `tools/census/build_mesh500.py` … zip解凍〜列抽出〜マージの再現スクリプト

### CSV 列構成

列名は同ディレクトリの `tools/census/mesh.py`(`MeshPop` リーダ)がそのまま読める形にしてある
(総数列 `total`、就業年齢列 `age20_69` を自動検出)。

| 列名 | 元列(T001101) | 内容 |
|------|--------------|------|
| `KEY_CODE` | KEY_CODE | 500mメッシュコード(9桁) |
| `total` | 001 | 人口総数 |
| `male` | 002 | 男 |
| `female` | 003 | 女 |
| `age_0_14` | 004 | 0〜14歳 |
| `age_15_64` | 010 | 15〜64歳(生産年齢人口) |
| `age_15plus` | 007 | 15歳以上 |
| `age_18plus` | 013 | 18歳以上 |
| `age_20plus` | 016 | 20歳以上 |
| `age_65plus` | 019 | 65歳以上 |
| `age_75plus` | 022 | 75歳以上 |
| `age20_69` | (016 − 019) | **就業年齢人口の近似値 = 20歳以上 − 65歳以上 = 20〜64歳** |

集計値: `total` 合計 60,353,849 / `age20_69` 合計 33,483,979(総人口の約55%、妥当)。


### 就業年齢人口(20〜69歳)についての注意

T001101 は**5歳階級ではなく累積しきい値**(20歳以上/65歳以上/75歳以上 …)での提供。
そのため「20〜69歳」ちょうどは算出不可(70歳以上の列が無い)。
最も近い代理指標として **`working_20_64` = 20歳以上 − 65歳以上(=20〜64歳)** を格納した。
- より就業実態に近い代替として `age_15_64`(15〜64歳の生産年齢人口)も利用可能。
- 5歳階級(20-24〜65-69の各列)が必須なら、e-Stat GIS の年齢5歳階級別メッシュ表(別statsId)か
  統計表APIの取得が別途必要(今回は総数系のT001101で要件充足と判断)。

## 5. 500mメッシュコード(KEY_CODE)の緯度経度からの算出方法

緯度経度↔500mメッシュコードの変換・半径圏集計は **`tools/census/mesh.py`** に実装済み(JIS X 0410準拠)。
- `latlng_to_mesh500(lat, lng)` → 9桁コード
- `mesh500_center(code)` → メッシュ中心の(lat,lng)
- `MeshPop(csv).trade_area(lat, lng)` → 半径500m/1km/2km圏の (総人口, 就業年齢人口)

半径圏の集計方法: 各500mメッシュ中心の緯度経度を復元し、物件からの距離(ハバサイン/平面近似)が
半径R以内のメッシュ人口を単純合計する(面積按分なし、500m格子なので500m/1km/2km比較には十分)。

使用例:
```python
from mesh import MeshPop
mp = MeshPop('tools/census/mesh500_pop.csv')
mp.trade_area(35.690, 139.700)   # 新宿駅
# {'m500': (390, 216), 'm1000': (32349, 20433), 'm2000': (211317, 131097)}
```

メッシュコードの構成(9桁): 1次(80km)4桁 + 2次(10km)2桁 + 3次(1km)2桁 + 4次(500m)1桁。
4次の下1桁は3次セルの2×2分割番号(南西/南東/北西/北東)。丸の内など常住人口ゼロの500mメッシュは
CSVに行が無い(=人口0として扱う)。

### 秘匿処理について
CSVの元データには `HTKSYORI`(秘匿区分: 0=通常/1=秘匿/2=合算先)列があるが、
500mメッシュでは秘匿はごく僅か。本CSVでは値が `*`/空欄のセルは 0 に変換して格納している。
