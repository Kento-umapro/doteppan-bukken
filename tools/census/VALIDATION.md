# 国勢調査メッシュ人口 精度検証（v4準備）

DataLens（KDDI/国勢調査由来）の実測商圏人口と、本リポジトリのメッシュ計算（`mesh.py`・面積按分）の突合。

## 検証結果（関東・近畿の既存9店・Geolonia町丁目座標）

| 圏 | 計算 vs DataLens実測 の平均絶対誤差 | 判定 |
|---|---|---|
| **1km** | 約10%（登戸: 計28,534 / 実32,888 = -13%、2km -7%） | ◎ 実用精度 |
| **2km** | 約10% | ◎ 実用精度 |
| **500m** | 約32% | △ 座標精度に敏感 |

## 所見

- **1km・2km圏は高精度**（±10%前後）。メッシュ数が多く座標誤差に強い。
- **500m圏は誤差が大きい**が、原因は計算方式ではなく**座標が町丁目重心（実店舗位置と数百mズレ）**であること。
  同一町丁目の登戸店・向ヶ丘遊園店が同じ値になる問題が典型。**Googleジオコーディング（建物精度）を使えば500mも収束**する見込み。
- 結論: v4の需要効率軸は **1km圏を実務の主軸**に、500mは正確な座標が取れる物件で加点補正に使うのが堅実。
  （売上との単相関は500mが最強 r=0.89 だが、計算精度を踏まえ1km r=0.63 を安定運用の軸に据える）

## データ
- `mesh500_pop.csv` … 令和2年国勢調査 500mメッシュ（関東+近畿 89,028メッシュ・6,035万人）。列に age20_69（就業年齢）あり。
- `mesh.py` … 緯度経度↔メッシュコード、半径圏の面積按分集計（4×4小区画サンプリング）。
- 未取得地域（北海道・愛知・福岡など）は今後の巡回で必要な1次メッシュを追加取得する。
